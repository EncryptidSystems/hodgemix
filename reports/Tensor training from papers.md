# Twelve maps rewrite stored weight arrays

The three folders support one purely tensor procedure, and it is a one-pass merge. Twelve closed maps read weight arrays and scalar mix weights and write weight arrays, in the order Algorithm 1 of the 14 October mix paper already writes, with Algorithm D standing in the lock slot and with every stage that reads a sentence, a tokenizer string, a label, a loss, or a backward pass left out. The 23 October Whitney proofs and the 31 October cubical note supply the resampling, prolongation, and cycle-band formulas those steps already name, under hypotheses those proofs actually state. Folder 02 adds no thirteenth write: its proved sentences classify a Künneth class, bound a metric that is already evolving, or multiply a scalar energy. The 81-token smoke table does not say that this chain improves a model. The unmixed 2B4T base sits at perplexity **12.0**, and the recorded mix, which still runs the excluded forward stages, sits at **14.4**. No paper in the three folders proves a quality theorem for the composition, and this report does not supply one.

The list below is that procedure. Each entry is a map a paper or a Proof environment writes down, with the array that enters, the array that leaves, and the hypothesis the source attaches. A second call of an idempotent map returns the same array, so the procedure is one pass. Scalar mix weights \(w_i\) are the only inputs that are not arrays. Nothing in the list is a new optimizer: there is no loss, no step size chosen to reduce one, and no loop that updates a weight until a threshold on a loss is met.

## Conclusion

The tensor test sorts the three folders by the kind of sentence they contain. Folder 01 writes formulas that copy, average, difference, or replace entries, and then writes the norms of those formulas. Folder 03 writes the order in which a merge program applies formulas of that kind to checkpoint arrays. Folder 02 writes sentences whose conclusion is that a class, a gap, or a distance to a prescribed metric stays where it already was. The sharp constant proved on 31 October, \(2^d\), multiplies a projection that fixes a coefficient array already in the discrete space, which is the kind of array a safetensors checkpoint already is. The smoke numbers measure a different program, the one that still reads the calibration sentences, and on that program the mixed run sits above the base.

A quality theorem would be a sentence that relates the output array to a loss, a perplexity, or a KL divergence, with the forward-dependent stages either included under a hypothesis or excluded by the same hypothesis. No document in the three folders contains that sentence. Running the twelve maps does not create it. The Gershgorin bound, the cubical bound, and the surgery count remain bounds on maps and on loops. They stay bounds after the pack is written.
